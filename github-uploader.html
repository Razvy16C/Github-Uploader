GitHub Folder Uploader

Upload a folder and its subfolders to a GitHub repository in one commit. No Git client subscription required.

1. Sign in to GitHub

Use a fine-grained token with repository access and Contents: Read and write. This is token-based sign-in, not your GitHub password. The token stays in this tab and is sent only to api.github.com.

3. Upload

This creates Git blobs, a tree, and one commit, then updates the selected branch. Files are uploaded directly from your device to GitHub.

Creating a token

  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Create a fine-grained token and grant access to the repositories you want to see here (or choose all repositories).
  3. Grant Contents: Read and write and Metadata: Read-only.
  4. Copy the token into this page. Do not share it or put it in a public repository.

For safety, use a short-lived/repository-limited token and revoke it after uploading if you no longer need it. Anyone who can access this page while the token is entered could potentially use it.
